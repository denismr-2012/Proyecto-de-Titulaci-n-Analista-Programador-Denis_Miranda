# Proyecto-de-Titulaci-n-Analista-Programador-Denis_Miranda
Sistema Web de Gestión de Movimientos y Traspasos de  Mercadería entre Sucursales Autostock 


El sistema permite centralizar el control de inventarios, optimizar los traslados entre sucursales y generar documentación confiable que respalda las operaciones.  
Fue desarrollado como proyecto de título aplicando el patrón **MVC**, con **Microsoft SQL Server** como motor de base de datos y tecnologías web estándar para la interfaz.

Objetivos
- Centralizar la gestión de stock en todas las sucursales.
- Optimizar los traslados de repuestos entre locales.
- Generar guías y reportes confiables para la toma de decisiones.
- Reducir pérdidas económicas y mejorar la experiencia del usuario.

Tecnologías utilizadas
- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Lógica bajo patrón MVC
- **Base de datos:** Microsoft SQL Server
